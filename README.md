# ⚡ NOVA Bio Link Bot ⚡

NovaBot is a Telegram security bot that protects your groups from spam links, unwanted users, and provides moderation tools.

## 📋 Features
- Bio & Name Scanner
- Whitelist System
- Auto Warn / Mute / Ban
- Owner Commands (Stats, Broadcast, Backup)
- Interactive Help Menu
